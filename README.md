# מתג הכיבוי של כלי המרת קורות החיים (מטריקס)

הקובץ `status.json` שולט אם הכלי עובד אצל כל המשתמשים.

## איך מכבים את הכלי לכולם
1. פותחים את הקובץ `status.json` כאן ב-GitHub.
2. לוחצים על העיפרון (Edit).
3. משנים `true` ל-`false`:  `{ "enabled": false }`
4. לוחצים **Commit changes**.

תוך כמה דקות הכלי יפסיק לעבוד אצל כולם ויראה "הכלי אינו זמין כעת".

## איך מחזירים לעבוד
אותו דבר, מחזירים ל-`{ "enabled": true }`.
